## 前言

"该怎样学习网络安全？"——几乎每个想入行的新人都会问这句话。网安方向多、知识点杂，一头扎进去很容易迷茫：该先学什么？学到什么程度才能打 CTF？为什么别人能解出题，我却连思路都没有？

这篇文章不打算给你一份"知识清单"，而是讲清楚**一条能走通的路**：学什么、怎么学、怎么把知识变成实战能力。核心就一句话——**以 CTF 为练兵场，以实战为主线，边学边打。**

## 一、先看清全景：网络安全到底学什么

网安不是一门课，而是一整个学科群。先建立地图，才知道自己站在哪、往哪走。CTF 竞赛恰好把它划分成了几个清晰的方向：

| 方向 | 学什么 | 一句话理解 | 入门难度 |
| ---- | ---- | ---- | ---- |
| **Web** | 网站漏洞攻防 | 攻击的是"网页背后的逻辑" | ★☆☆ |
| **Misc** | 隐写、取证、编码 | 各种"藏信息"和"找信息" | ★☆☆ |
| **Crypto** | 密码学 | 加密、解密、破译 | ★★☆ |
| **Reverse** | 逆向工程 | 还原程序逻辑、破解 | ★★★ |
| **Pwn** | 二进制漏洞利用 | 攻击程序本身、拿权限 | ★★★ |

**新手怎么选？** 建议从 **Web + Misc** 入手——这两个方向见效快、题量大、最容易建立正反馈。等基础扎实了，再根据自己的兴趣往 Crypto、Reverse、Pwn 深耕。

## 二、零基础怎么起步：先学会这三样

很多人急着直接学漏洞，结果卡在看不懂 HTTP 请求、不会写脚本上。地基不牢，后面寸步难行。第一步先把这三样学会：

### 1. 计算机网络基础

网络安全本质是"网络"的安全，Web 题几乎全建立在 HTTP 协议上。

- 理解 TCP/IP 分层、三次握手、常见端口（80/443/22/3306 等）；
- 吃透 HTTP：请求方法、状态码、Cookie/Session、请求头各字段的含义；
- 会用 Wireshark 抓包、会用浏览器 F12 分析请求。

> **实战技巧**：动手抓一次自己的请求，观察一个登录过程到底发了什么——比背十页协议书都有用。

### 2. 熟悉一门编程语言

编程语言建议选 **Python**——网安几乎所有方向都用得上：写脚本、发请求、处理数据、写 POC。先学精一门即可，不必贪多。如果后续想往 **Pwn / Reverse（二进制方向）** 发展，C 语言是绕不开的地基，可以 Python 之外再补一本 C。

- 语法基础、字符串与字典操作、正则表达式；
- `requests` 库（HTTP 请求）、`socket`；
- 目标不是"成为程序员"，而是**能看懂别人的脚本并改、进而自己写小工具**。

### 3. 掌握人工智能使用思路

现在学网安，AI 是必须会用的一把"杠杆"。它不替你学，而是帮你把学习效率翻倍。关键不是会用某个工具，而是**建立"什么时候该问 AI、怎么问"的思路**：

- **解释概念**：卡在某个知识点时，让 AI 用通俗的话讲清楚；
- **辅助读题**：CTF 题面看不懂时，让 AI 帮你分析考点、给思路（但别直接要答案）；
- **辅助写/改脚本**：让 AI 生成脚本框架、解释报错、优化代码；
- **对比与纠错**：把你和 AI 的思路对比，发现自己的知识盲区。

> **心法**：把 AI 当"会说话的教科书 + 陪练"，而不是"答案生成器"。自己先想，想不出再问，问完要真正弄懂——否则等于没学。

### 4. 顺手要会的环境与工具

打 CTF 离不开 Linux 环境和几个核心工具，边学边熟悉即可：

- **Linux 基础**：文件操作、用户与权限、进程管理，以及 `grep`/`sed`/`awk`。建议装一个 Kali Linux 虚拟机；
- **Burp Suite**：Web 核心工具，抓包、重放、爆破、改包；
- **F12 开发者工具**：看源码、看请求、改参数；
- **Nmap / Wireshark**：端口扫描、流量分析。

## 三、掌握实战技巧：学一个，会一类

这是本文最重要的部分。很多人学网安的方法是"看视频、记笔记"，结果一看就会、一做就废。真正拉开差距的，是**掌握"把一个知识点变成实战能力"的方法**。

### 实战三步法：原理 → 复现 → 变式

拿 **SQL 注入**举例：

1. **原理**：搞清楚为什么会发生——用户输入被拼接进 SQL 语句，导致查询被篡改；
2. **复现**：在靶场亲手打出来。用 DVWA、sqlilabs，从最简单的一关开始，一步步注入、拿到数据；
3. **变式**：换个环境、换种过滤，还能不能打？比如加了 `waf`、过滤了空格和注释符，怎么绕过？

> **核心心法**：**学一个漏洞，不是记住一个 payload，而是理解它的成因和利用条件。** 因为 CTF 永远不会原题出现，考的是你"换皮之后还认不认识它"。

### Web 必学的几类实战漏洞

| 漏洞 | 实战要点 |
| ---- | ---- |
| SQL 注入 | 会判断注入点、会闭合引号、会绕过过滤 |
| XSS | 分清反射/存储/DOM 型，会构造 payload |
| 文件上传 | 会绕过后缀、MIME、内容校验，getshell |
| 命令执行 | 会拼接命令、绕过过滤、读取 flag |
| 文件包含 | 会用伪协议（php://、data://） |
| SSRF | 会用服务器代理访问内网资源 |
| 反序列化 | 理解序列化机制，构造恶意数据 |

### 靶场推荐（动手优先）

学完理论立刻上手，这两个平台注册即可开刷：

- **[青岑网安（QingCen CTF）](https://ctf.qingcen.net/)**：CTF 练习平台，提供习题、题目集和赛事，题目分类清晰，适合入门刷题；
- **[CTF+](https://www.ctfplus.cn/)**：CTF 赛事与安全服务平台，注册后同样可以练题刷题。

经典靶场也可以配合使用：

- **DVWA / sqlilabs**：经典漏洞靶场，难度分级，适合一个个漏洞打过去；
- **PortSwigger Academy**：Burp 官方出的免费 Web 安全平台，案例真实、讲解透彻。

### 自己搭建靶场：把环境握在自己手里

在线平台练熟了之后，下一步是**自己搭靶场**。搭环境的意义不只是"有个地方练手"，而是逼你把环境、服务、漏洞三者彻底搞懂。

- **Docker + Vulhub（最推荐）**：Vulhub 收录了大量真实漏洞的复现环境，一条命令就能拉起，例如 `docker compose up -d`；
- **DVWA / sqlilabs 本地部署**：亲手搭一套 PHP + MySQL 环境，从安装到配置都走一遍，顺便把 Web 部署流程也学了；
- **自己写靶场**：用 Python / Node 写一个"故意有漏洞"的小页面，比如一个不做过滤的登录接口，然后亲手把它打穿——**这是理解漏洞成因最深刻的方式**。

> **心法**：能打别人的题不算真会，能自己搭出环境、甚至自己造出题，才算把知识内化了。很多进阶选手的终极练习，就是"自己出题自己解"。

## 四、CTF 怎么打：从刷题到比赛

学得再多，不上"战场"都是空的。CTF 就是那张战场。

### 1. 入门与刷题平台

- **[Hello CTF](https://hello-ctf.com/)**：开源免费的 CTF 入门教程，从零开始带你拿下第一面 flag，**新手必看**；
- **BUUCTF**：经典题库，Writeup 丰富；
- **攻防世界**：国内外真题、难度分级；
- **CTFshow**：专题化、阶梯式，适合专项突破；
- **NSSCTF**：新题多、社区活跃。

### 2. 先定方向：一主一辅

刷题最忌讳"看到什么刷什么"，五个方向平摊精力，最后哪个都不精。正确做法是：

1. **找到自己喜欢的方向**：把 Web、Misc、Crypto、Reverse、Pwn 都简单体验一遍，哪个方向让你"解完还想解下一道"，就是它了；
2. **选两个方向，一主一辅**：
   - **主方向**：投入约七成精力，深耕到底，成为你的核心竞争力；
   - **辅方向**：投入约三成精力，作为补充，比赛时既能帮队友分担，也能扩大得分面。

> 为什么不"专精一个"也不"全都要"？只专精一个，比赛里碰到短板题型就抓瞎；全都要，则每个方向都浮在表面。**一主一辅**是效率与覆盖面之间的最佳平衡。

### 3. 刷题的正确姿势

很多新手刷题，一看没思路就直接看题解，这样等于没刷。推荐**三遍刷题法**：

1. **第一遍**：自己独立做，卡住了先想 15 分钟，实在不行才看提示（不是看答案）；
2. **第二遍**：看懂答案后，关掉答案自己重新打一遍，把关键步骤背下来；
3. **第三遍**：隔几天再回来，看看还能不能独立复现——能，才说明真的会了。

> **实战技巧**：每道题都写一份简短的 **Writeup**（解题思路），哪怕只有几句话。写 WP 是巩固知识最快的方式，也是网安求职的重要积累。

### 4. 参加比赛

- 先从**线上赛**入手，关注 CTFtime 和国内高校、企业的公开赛；
- **组队很重要**：找 2~3 个方向互补的队友（你 Web 强，队友会 Pwn/Crypto），分工协作；
- 比赛时间有限，学会**取舍**：先做自己擅长的、分值高的题，别死磕一道。

## 五、一份可执行的学习路线

以每天投入 1~2 小时估算，分四个阶段：

| 阶段 | 时间 | 内容 | 检验标准 |
| ---- | ---- | ---- | ---- |
| 一、打基础 | 第 1~2 个月 | 网络基础、一门编程语言、AI 使用思路、工具 | 能用 Python 发请求、会借助 AI 高效学习 |
| 二、Web 实战 | 第 3~4 个月 | 常见漏洞原理与利用 | 独立完成 DVWA 全难度，解出基础 Web 题 |
| 三、选方向 | 第 5~6 个月 | 定主辅两个方向并深耕（Web/Crypto/Pwn…） | 形成一主一辅的优势组合 |
| 四、以赛代练 | 持续 | 刷题、打比赛、写 WP | 稳定出题，能带队分工 |

### 一周节奏参考（以阶段二为例）

| 星期 | 任务 |
| ---- | ---- |
| 周一 | 学一个漏洞的原理 |
| 周二 | 靶场复现该漏洞 |
| 周三 | 在 CTF 平台刷 2~3 道对应类型的题 |
| 周四 | 学下一个漏洞原理 |
| 周五 | 复现 + 刷题 |
| 周末 | 复盘本周题目，写 WP，补漏洞 |

## 六、资源清单与避坑

### 资源

- **书籍**：
  - 计算机网络：《计算机网络：自顶向下方法》（经典教材，重点推荐）；
  - 编程语言：《Python 编程：从入门到实践》《C 语言程序设计：现代方法（第 2 版·修订版）》(K.N.King)；
  - Web 安全：《Web 安全深度剖析》《白帽子讲 Web 安全》；
  - CTF：《从 0 到 1：CTFer 成长之路》；
- **平台**：PortSwigger Academy、TryHackMe、HackTheBox；
- **文档**：OWASP Top 10、各语言官方文档；
- **社区**：先知社区、FreeBuf、安全客。

### 新手常踩的坑

1. **囤资料不学**：网盘存了一堆，从没打开过。资料够用就行，把时间留给动手。
2. **只会用工具**：离了"一键工具"就不会打。工具是拐杖，原理才是腿。
3. **贪多嚼不烂**：五个方向都碰，结果都不精。按"一主一辅"来，先把主方向做深。
4. **一卡壳就翻答案**：等于没练。用"三遍刷题法"，逼自己先想。

## 结语

网络安全和 CTF 是一条需要长期投入的路，但它最迷人的地方在于——**每一分努力，都能在拿到 flag 的那一刻得到回报**。这份指南是地图，真正让你走到终点的，是持续动手和不断复盘。

希望明年的今天，你也能写出属于自己的 Writeup。共勉 💪
